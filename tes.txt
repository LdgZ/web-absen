III. DATABASE SCHEMA (PRISMA)
model User {
  id        String   @id @default(cuid())
  email     String   @unique
  password  String   // hashed
  name      String
  role      Role     @default(TEACHER)
  createdAt DateTime @default(now())
  classes   Class[]
}

enum Role {
  ADMIN
  TEACHER
  PARENT
}

model Class {
  id          String      @id @default(cuid())
  name        String      // "Kelas 3A"
  teacherId   String
  teacher     User        @relation(fields: [teacherId], references: [id])
  students    Student[]
  attendances Attendance[]
}

model Student {
  id          String       @id @default(cuid())
  nis         String       @unique
  name        String
  classId     String
  class       Class        @relation(fields: [classId], references: [id])
  parentName  String
  parentPhone String       // format: 628123456789
  photoUrl    String?
  attendances Attendance[]
  createdAt   DateTime     @default(now())
}

model Attendance {
  id         String           @id @default(cuid())
  date       DateTime
  status     AttendanceStatus
  note       String?
  proofUrl   String?          // surat sakit/izin
  studentId  String
  student    Student          @relation(fields: [studentId], references: [id])
  classId    String
  class      Class            @relation(fields: [classId], references: [id])
  createdAt  DateTime         @default(now())
  
  @@unique([studentId, date])
}

enum AttendanceStatus {
  HADIR
  SAKIT
  IZIN
  ALPHA
}

model SMSLog {
  id        String   @id @default(cuid())
  phone     String
  message   String
  status    String   // sent, failed
  sentAt    DateTime @default(now())
}

KESIMPULAN & REKOMENDASI
✅ Perubahan Utama dari Spec Awal:
1.Next.js instead of React + Express → Lebih simple, 1 codebase
2.PostgreSQL instead of SQLite → Production-ready dari awal
3.Fonnte instead of Twilio → Lebih cocok untuk Indonesia
4.Resend instead of Brevo → Developer-friendly API
5.UploadThing instead of Cloudinary → Better DX, generous free tier
6.Remove: OAuth, 2FA, Lottie → Keep it simple for MVP
7.Add: Offline support, keyboard shortcuts, optimistic updates
💡 Tips Implementasi:
Start small: Buat MVP dulu (Week 1-2), jangan langsung semua fitur
User feedback: Deploy early, minta feedback dari 1 guru dulu
Iterate fast: Update setiap 2-3 hari based on feedback
Document: Buat video tutorial 5 menit untuk onboarding

✅ Guru bisa absen 1 kelas (30 siswa) dalam < 2 menit
✅ Load time dashboard < 2 detik
